# jarvis-asistan

A personal artificial intelligence voice assistant developed in Python, featuring speech recognition and Gemini API integration.

## Features
* **Voice Command:** Recognizes voice commands using the 'speech_recognition' library.
* **AI Intelligence:** Provides smart responses using the Gemini API integration.
* **App & Web Control:** Opens apps, websites like Google, and Youtube via voice commands.

## Technologies Used
* Python 3
* 'speech_recognition'
* Gemini API
